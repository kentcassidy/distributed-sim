WHAT WAS BUILT (all under viz/)
-------------------------------
1) RUN-AWARE INGEST + RUN SELECTOR
   - vite.config.js dev endpoint now serves runs: /sim_out/index.json -> {runs}, then
     /sim_out/<run>/index.json -> {files}, then the raw files. Old flat files still load
     as a run named "(root)".
   - loader.js: listRuns() + loadRun(run). App.vue: a Run dropdown; switching resets the
     per-run UI state + playhead.

2) CONTROLLER INTERPRETATION (timeline.js)
   - The controller source is identified unambiguously by a `world` field in its meta.
     Its world bounds + owner-tagged sectors are captured; it contributes NO tracks and
     does not appear as a federate.
   - Fleet = federates that fly aircraft PLUS any sector owner, so a federate owning an
     empty slab still shows (with a color + a slab). Names sorted for stable colors.
   - Timeline now carries .world and .sectors.

3) PARTITION RENDERING (SceneController.js + worldspace.js) — the thesis
   - Pane mode keys off its filter: exactly one federate (that owns a slab) = PARTITION
     view; all/multiple = standard/FUSED view.
   - Fused: whole-world gridded, shaded room (flush to controller `world`).
   - Partition: the whole world drops to a quiet edge wireframe (+axes); that federate's
     own slab is the lit gridded room, walls tinted toward its owner hue.
   - "Sectors" toggle = the global reveal (every slab's fat edges + a faint face tint).
   - Per-federate "highlight bounds" = solid FAT edges (LineSegments2, ~1px thicker than
     WebGL basic lines can do), filter-independent so you can light up OTHER partitions
     from inside a pane. Halo = finer dashes, a touch more opaque.
   - Camera: fused frames the whole world (user's stated default); partition frames its
     slab. Aircraft stay small in X because the split is Y-only over a 20 km world -> the
     per-aircraft tracking feature (below) is the real fix.

4) COSMETIC PASS
   - Always-on outer EDGES: buildEdgeFrame draws all 12 limit edges, never culled, so the
     box reads as a box from any angle even where a face grid is hidden. Near edges (those
     shared by two hidden faces) render solid but faint (opacity 0.25); far edges full.
   - Slab outer edges use the OWNER color, so they separate from the grey world wireframe.
   - ISOMETRIC FIX: wall culling, the near/far edge test, AND the units' nearest-edge pick
     now use the orthographic view DIRECTION (getWorldDirection), not the camera point.
     One helper, faceNear(), drives all three so perspective + isometric agree.
   - Units: sit closer to the edge (offset 0.015 -> 0.004 of extent); in a partition pane
     they attach to the SLAB bounds (per-partition units), world in fused.
   - New toggles: "World frame" (hide the whole-world wireframe in a slab view, keeping
     the axes) and "Tint" (owner-hue tinting globally). Partition tint reduced ~30%
     (PARTITION_TINT 0.22 -> 0.15).

5) FEATURES (backlog #1, #2, #4)
   - #2 Global size multiplier: a slider (exp map, centered 1x, 0.125x..8x, dbl-click
     reset) scaling every federate marker on top of their own sliders.
   - #1 Gizmo axis-click: click a gizmo axis knob to snap the view down that axis (X/Y
     keep Z up; Z is top-down with +Y up). Capture-phase hit-test with an invisible
     larger target per knob; stopPropagation so it doesn't also start an orbit drag.
   - #4 Per-aircraft camera tracking: "Track camera" per aircraft; zooms in and follows
     it each frame (preserving relative orbit/zoom) while the default framing stays the
     whole world. Only acts in panes showing that aircraft; clears on run switch.

6) QoL ADDENDUM (end of session)
   - Per-aircraft ORIENTATION in the stats: heading/pitch/roll (deg) derived from the
     reported quaternion (config.js quatToEulerDeg; Z-up, nose +X). Longitudinal filler
     shows pitch ~1 deg, heading/roll ~0.
   - Units DECLUTTER: _updateLabels thins tick labels by on-screen spacing each frame
     (project -> hide any within MIN_LABEL_PX=22 of the last kept), so zoomed-out views
     keep only spaced indicators and fill back in on zoom-in.
