WHAT WAS BUILT (all under viz/, walled off from the C++/CMake build)
--------------------------------------------------------------------
Stack: Vue + Vite + Three.js (plain Three inside a Vue component; TresJS skipped for
legibility). Dev server only; the federate still just EMITS NDJSON. World is Z-UP
(sim z = altitude, like Blender); axes X-red/Y-green/Z-blue.

- Auto-ingest: a Vite dev plugin serves repo-root sim_out/ (index.json + files); the
  loader parses + merges the per-federate NDJSON into one Timeline (lerp pos, nlerp
  quat, data bounds). Verified against the real F1/F2 files.
- Playback: a SHARED clock (viz/src/viewport/clock.js) advanced once/frame by App and
  read by every viewport, so all panes stay in sync. Play/pause, scrub, speed; keyboard
  transport (Space; arrows +/-1ms; Shift +/-1s; Ctrl +/-5s).
- Worldspace: a volumetric "room" showing only interior-facing walls (matches BackSide
  color); grids on those walls with major/minor lines at ONE global step (square cells);
  thin arrowed RGB axes; constant-size (CSS2D) tick UNITS parked on the nearest edge
  attached to a visible wall (incl. Z); a Blender-style corner orientation gizmo (XYZ
  labels live there). Isometric (orthographic) toggle. Color box renders behind planes
  (no wing clipping). Recenter (world + per-federate), resetting to the initial angle.
- Control panel (now TWO collapsible panels, Controls | Aircraft): per-federate
  show/hide/highlight(bounding box)/halo/size; per-aircraft show/hide/highlight +
  live stats; aircraft list sort/filter by federation (sticky group headers) + an
  "only active federations" sync.
- Per-federate VIEWPOINTS: multiple synced viewports — Fused | Separated x All |
  Selected. Separated lays out a square-ish grid (cols=ceil(sqrt N), vertical split
  first), leftover cells hold a Fused view. Panes carry a title and a federate-colored
  border on hover, three-way synced (aircraft row <-> federate slot <-> pane).
