Instructions from README.txt
 Running on Unbuntu 12.04 LTS
 -----------------------------
 To run on Ubuntu, ensure you have g++ installed and then open a command prompt,
 change into the directory, compile and run using the script:

   * cd $RTI_HOME/examples/cpp/ieee1516e
   * ./linux64.sh compile
   * ./linux64.sh execute

Due to this version of Portico using C++11, we must conform to older build standards including:
	-std=gnu++14			must be used to as older dynamic throw()-specs and auto_ptr were deleted in C++17
	-D_GLIBCXX_USE_CXX11_ABI=0	std::string/wstring memory layouts used to use Copy-on-Write. If not accounted for, will lead to segfaults.
